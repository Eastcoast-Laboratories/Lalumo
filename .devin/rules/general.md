# General Behavioral Rules

Follow these behavioral rules when working on this project.

- Do not work through the project dev/TODO.md list autonomously. Wait for explicit user instructions.
- Never deploy, run `git reset`, `git checkout`, or `rm` unless explicitly asked.
- Never commit changes unless explicitly asked.
- Be critical and verify user assumptions before agreeing. Avoid flattery.
- When editing an existing file, continue in the same language already used in that file. Do not mix languages within a file.
- Keep temporary files in `/var/tmp/devin/` instead of `/tmp`. Use `test/` for test files that should persist.
- Begin non-final updates with a sequential number, the date/time in `D.M. H:i` format, and a short topic word in quotes.
- Final summary messages must begin with `Fertig!`.
