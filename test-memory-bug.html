1_5 Memory Game Bug Reproduction Test

Manual Test Instructions

1. Open the main app at http://localhost:9091/app/

2. Click the debug button "🎹 Memory Game" (nav_1_5) to navigate to 1_5 memory game

3. Click the Play button multiple times and watch console logs

4. Look for BUG_DEBUG logs to track the issue

Expected Bug Behavior

  • First play: Should work - logs show "BUG_DEBUG: playCurrentMelody() called" and "PIANO_DIRECT Starting memory sequence playback"
  • Second play: Bug may occur - might not show PIANO_DIRECT logs
  • Third play: Further verification of bug

Debug Logs to Watch For

Normal Flow:
BUG_DEBUG: playCurrentMelody() called - mode: 1_5_pitches_memory-game, gameMode: false/true
BUG_DEBUG: 1_5 memory game path - gameMode: false/true
BUG_DEBUG: Starting new memory game (gameMode=false) OR BUG_DEBUG: Replaying memory sequence (gameMode=true)
PIANO_DIRECT Starting memory sequence playback with X notes
Bug Indicators:
- Missing PIANO_DIRECT logs on subsequent plays
- BUG_DEBUG: playMemorySequence() EARLY RETURN - no sequence!
- Inconsistent gameMode states

Race Condition Tests

Try these specific scenarios to trigger the bug:

  1. Rapid Clicks: Click Play button 2-3 times rapidly within 100ms
  2. Success Auto-play Interference: Complete a sequence correctly, then click Play during the 2s auto-play window
  3. Error Recovery Interference: Make an error, then click Play before the 2s error recovery timeout
  4. Cross-activity Pollution: Switch from another activity while sound is playing, then use 1_5 Play button
